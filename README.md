# Корпоративный портал сотрудников (Django)

Веб-приложение для управления каталогом специалистов компании, их профессиональными навыками, рабочими местами и портфолио. Проект полностью покрыт автоматическими тестами и оптимизирован для работы с базой данных.

## 🚀 Реализованный функционал (Соответствие критериям оценки)

- **Учёт стажа:** В модель сотрудника добавлено поле даты приёма на работу (`date_joined`).
- **Карточки сотрудников:** Настроена детальная разметка карточек. Они содержат ФИО, пол, ключевые навыки, первое изображение из галереи и динамически вычисляемый стаж работы в днях.
- **Главная страница:** Отображает общее количество сотрудников в БД и карточки 4-х последних нанятых специалистов.
- **Пагинация каталога:** На странице полного списка сотрудников настроен постраничный вывод (по 10 человек на страницу).
- **Разделение галереи:** На подробной странице сотрудника первое изображение выводится как главное заглавное фото, а остальные фотографии отображаются ниже в виде отдельного портфолио.
- **Оптимизация (Prefetch Related):** Исключена проблема N+1 запросов за счёт предзагрузки связанных картинок и навыков во всех ключевых контроллерах (Views).
- **Жесткий валидатор рассадки:** Написана бизнес-логика на уровне модели, запрещающая размещать тестировщиков (`qa`) и разработчиков (`backend`, `frontend`) за соседними столами (+/- 1 от номера стола).
- **Качество кода:** Код задокументирован в стиле *Google Style Docstrings* и полностью соответствует стандартам **PEP8**.

## 🧪 Автоматическое тестирование (Django Unittest)

В проекте реализовано 8 тест-кейсов на базе встроенного фреймворка `django.test.TestCase` (`unittest`), которые изолированно проверяют систему по следующим критериям:
- **Тестирование доступности и структуры контекста главной страницы.
- **Тестирование доступности каталога и наличия пагинатора в контексте.
- **Тестирование прав доступа (анонимные пользователи блокируются и перенаправляются на авторизацию, авторизованные — получают успешный доступ к карточкам).
- **Комплексный тест валидатора столов (проверка блокировки при нарушении соседства и успешное сохранение на безопасном расстоянии).

Запуск всех тестов:
```bash
python manage.py test
```

## 🛠 Инструкция по локальному запуску

### 1. Подготовка окружения
Активируйте ваше виртуальное окружение:
```bash
# Windows (PowerShell)
venv\Scripts\activate
```

### 2. Установка зависимостей
Установите библиотеки, зафиксированные в файле конфигурации:
```bash
pip install -r requirements.txt
```

### 3. Применение миграций
Создайте и примените структуру таблиц в базе данных:
```bash
python manage.py makemigrations
python manage.py migrate
```

### 4. Создание администратора
Создайте суперпользователя для управления сотрудниками и столами через Django Admin:
```bash
python manage.py createsuperuser
```

### 5. Запуск сервера
Запустите локальный сервер разработки:
```bash
python manage.py runserver
```
- Главная страница: `http://127.0.0`  
- Панель администратора: `http://127.0.0admin/`
